# Automation exports

The old database-coupled n8n workflow exports have been removed from the active HiveQuote branch.

HiveQuote automation is being rebuilt around Hedy-native data, functions, jobs, event inboxes, retry/replay handling, and audit evidence. n8n/Make may later be used as an integration adapter, but it must not become the authoritative routing, identity, consent, or financial state machine.

See `../SCENARIOS.md` and `../docs/HEDY-NATIVE-MIGRATION.md`.
